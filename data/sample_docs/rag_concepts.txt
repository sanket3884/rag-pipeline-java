Retrieval-Augmented Generation, or RAG, is a technique for improving the outputs of large language models by giving them access to external knowledge at query time, rather than relying solely on what was baked into the model's parameters during training. Instead of asking the model a question directly, a RAG system first retrieves relevant pieces of text from a knowledge base and includes them in the prompt as context.

A typical RAG pipeline has four stages. First, ingestion: source documents are split into smaller chunks, because embedding models and language models both have limited context windows and work better with focused passages rather than entire documents. Second, embedding: each chunk is converted into a numeric vector using an embedding model, such that semantically similar text produces vectors that are close together in the vector space. Third, retrieval: when a user asks a question, the question itself is embedded, and a vector similarity search finds the chunks whose vectors are closest to the question's vector. Fourth, generation: the retrieved chunks are inserted into a prompt along with the original question, and a language model generates an answer grounded in that retrieved context.

RAG has several advantages over fine-tuning a model on new data. It's cheaper and faster to update, since adding new documents just means indexing them, rather than retraining a model. It also makes answers more auditable, since the retrieved sources can be shown to the user as citations. And it reduces hallucination, because the model is instructed to answer based on provided context rather than from memory alone, though it does not eliminate hallucination entirely.

Common failure modes in RAG systems include: chunking that splits related information across chunk boundaries, poor embedding quality that fails to retrieve genuinely relevant passages, retrieving the wrong number of chunks (too few loses context, too many dilutes the prompt with noise), and prompts that don't clearly instruct the model to stick to the provided context.
